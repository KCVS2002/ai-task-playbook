# AI Task Playbook

Codex와 제한된 시간 안에 과제를 수행할 때 사용하는 개인용 작업 지침입니다.
요구사항 확인, 업무 질문, 최소 구현, 검증, 제출 점검을 돕는 범용 자료입니다.

## 사용 방법

1. 허용된 방식으로 이 저장소를 작업 환경에 가져옵니다.
2. **실제 과제 폴더**에서 Codex를 실행합니다.
3. `workflow.md`의 경로를 알려주고 다음처럼 요청합니다.

   > 이 파일을 읽고, README와 제공 자료를 확인해서 이번 과제에 맞는 질문과 진행 계획부터 정리해줘.

4. Codex가 제안한 업무 질문을 검토하고, 필요한 질문은 본인이 담당자에게 전달합니다.
5. 답변과 판단을 Codex에 전달하고, 합의한 범위 안에서 구현과 검증을 진행합니다.

`workflow.md`는 **직접 읽게 하는 일반 Markdown 지침**입니다. Plugin이나 MCP 설치가 필요하지 않으며, Skill 자동 등록을 가정하지 않습니다.

## 우선순위

- 실제 환경의 최신 규정, 제공 지침, 과제 요구사항을 우선합니다.
- 이 문서는 규정을 해석하거나 사용 권한을 부여하지 않습니다.
- 기존 지침 파일을 덮어쓰거나 플랫폼 설정을 변경하지 않습니다.
- 외부 자료의 다운로드 허용과 과제 자료의 외부 전송 허용은 구분합니다.
- 도구를 추가할 때는 제공 버전과의 호환성, 권한, 외부 전송 여부를 확인합니다.

## 공개 범위

범용 절차와 요청문만 포함합니다. 실제 과제 문제, 데이터, 답안, 작업 결과, 대화 기록, 계정 정보는 이 저장소에 올리지 않습니다.
공개 상태 유지 기간 등 사용 조건은 해당 환경의 최신 안내를 따릅니다.

## 바로 시작할 때

Codex에 다음처럼 요청합니다. 정확한 문장을 외울 필요 없이 저장소 주소와 파일명을 전달하면 됩니다.

> https://github.com/KCVS2002/ai-task-playbook 의 workflow.md를 가져와서 읽고, 현재 과제 폴더의 README와 제공 자료를 확인해서 질문과 진행 계획부터 정리해줘. 과제 폴더와 기존 지침은 유지해줘.

필요하면 [workflow.md](./workflow.md)를 열어 단계별 요청문을 참고합니다.
