# AI Task Playbook

Codex와 제한된 시간 안에 과제를 수행할 때 쓰는 개인용 작업 지침과 도구 선택 자료입니다.
특정 과제의 답안이나 데이터를 포함하지 않습니다. 실제 환경의 최신 규정과 제공 지침을 우선합니다.

## 가장 간단한 시작

Codex에 저장소 주소와 파일명만 전달합니다. 정확한 문장을 외울 필요는 없습니다.

> https://github.com/KCVS2002/ai-task-playbook 의 README.md와 workflow.md를 별도 참고 폴더로 가져와서 읽어줘. 현재 과제의 README와 자료를 확인하고, 필요한 질문과 진행 계획부터 정리해줘. 기존 과제 파일은 덮어쓰지 마.

다운로드한 Markdown은 제공된 IDE 에디터에서 열어 읽을 수 있습니다.
외부 브라우저 직접 접근이 제한된 환경에서는 Codex·터미널을 통한 허용된 다운로드 경로를 사용합니다.
차단되면 우회하지 않고 제공된 문의 경로를 따릅니다.

## 바로 읽어 쓰는 작은 Skill

| Skill | 목적 | 파일 |
|---|---|---|
| clarify-task | 목표·필수조건·업무 질문·완료 기준 정리 | [SKILL.md](skills/clarify-task/SKILL.md) |
| verify-deliverable | 기대값과 실제 실행 결과 비교 | [SKILL.md](skills/verify-deliverable/SKILL.md) |
| debug-reproduce | 오류 재현 → 원인 분리 → 수정 → 재검증 | [SKILL.md](skills/debug-reproduce/SKILL.md) |

먼저 관련 SKILL.md만 명시적으로 읽게 하는 방식으로 사용할 수 있습니다.
정식 등록은 선택 사항이며, 파일을 다운로드했다고 자동 등록되는 것은 아닙니다.
지원 환경에서 묶어서 사용할 수 있도록 Skill 전용 Plugin 명세도 포함했습니다.
이 명세만으로 설치되거나 외부 서비스가 연결되지는 않습니다.

## 운영 원칙

- 처음에는 README와 workflow만 읽고 나머지는 필요할 때 읽습니다.
- 도구가 필요하면 이점·호환성·권한·설정 시간·실패 시 대안을 확인합니다.
- MCP와 Plugin은 과제에서 필요한 기능이 있을 때만 선택합니다.
- 제공 AI 도구의 버전, 감독·보안 설정, 기존 프로젝트 지침을 변경하지 않습니다.
- 공개 자료를 가져오는 것과 과제 자료를 외부에 전송하는 것을 구분합니다.
- 실제 문제, 데이터, 결과물, 대화 기록, 키·토큰은 이 저장소로 올리지 않습니다.
- 사용한 자료의 주소와 범위를 기록하고, 요구된 공개 유지 기간을 준수합니다.
